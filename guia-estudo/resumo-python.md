## 📌 Resumo 
Python é uma linguagem de programação de alto nível, amplamente utilizada em automação, desenvolvimento web, ciência de dados e Inteligência Artificial. Sua sintaxe simples facilita o aprendizado e acelera o desenvolvimento de aplicações.

# 📚 Glossário

| Conceito | Definição |
|---|---|
| Variável | Espaço utilizado para armazenar dados |
| Função | Bloco reutilizável de código |
| Loop | Estrutura de repetição |
| Lista | Estrutura de dados ordenada |
| Dicionário | Estrutura baseada em chave e valor |
| Prompt Engineering | Técnica de criação de prompts para IA |
| IA Generativa | Inteligência Artificial capaz de gerar conteúdo |
