# Prompts

# 🤖 Engenharia de Prompts Durante o desenvolvimento deste caderno temático, diferentes estratégias de prompts foram testadas para melhorar a qualidade das respostas geradas pela IA. 
## Exemplos de prompts utilizados ### 

### Prompt inicial

Explique funções em Python.

### Prompt refinado

Explique funções em Python com exemplos práticos e foco em iniciantes.

### Prompt contextualizado

Explique funções em Python como se estivesse ensinando alguém vindo do Java.

# 🧩 Prompts Reutilizáveis

Explique esse conceito em Python com exemplos simples.

Crie exercícios práticos sobre esse tema.

Compare esse conceito entre Python e Java.

Explique esse erro e como resolver.


# ⚠️ Dificuldades Encontradas 
- Respostas muito genéricas
- Falta de exemplos práticos
- Necessidade de prompts mais específicos
- Ajuste do contexto para obter respostas mais úteis
