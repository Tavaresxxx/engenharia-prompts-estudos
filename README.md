# 🐍 Caderno Temático — Python com IA Generativa 


## 📌 Sobre o Projeto

Este repositório foi criado como um caderno temático de estudos utilizando o NotebookLM como ferramenta de apoio ao aprendizado.
O foco principal é aprofundar conhecimentos em Python, explorando conceitos fundamentais da linguagem, boas práticas de programação e aplicações no contexto de Inteligência Artificial e análise de dados.
Além do estudo técnico, este projeto também documenta experimentos com Engenharia de Prompt, curadoria de conteúdo e uso de IA Generativa para apoio educacional.

# 🎯 Objetivos

- Aperfeiçoar conhecimentos em Python
- Desenvolver raciocínio lógico e resolução de problemas
- Aprender boas práticas de programação
- Explorar técnicas de Prompt Engineering
- Utilizar IA como ferramenta de apoio aos estudos
- Criar um material reutilizável para futuras revisões

# 🧠 Temas Estudados

- Sintaxe básica do Python
- Estruturas condicionais
- Laços de repetição
- Funções
- Listas, tuplas e dicionários
- Manipulação de arquivos
- Programação orientada a objetos
- Bibliotecas Python
- Automação
- Introdução à análise de dados


- # ✅ Estratégias Aplicadas

- Comparações entre Python e outras linguagens
